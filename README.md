# BNBU-Course-Project
A portfolio of projects from over four years of undergraduate coursework, covering AI, data analytics, optimization, software development, and fintech.

# Undergraduate Course Projects

This repository brings together projects I worked on over more than four years of undergraduate coursework. They range from building a classroom booking system in C to comparing deep learning optimizers and developing a prototype ETF trading dashboard.

The collection includes source code, notebooks, reports, presentation slides, and dashboards where available. Many of these projects were completed in teams, with contributions shared among group members.

## Project Index

| Course area | Project |
| --- | --- |
| [Artificial Intelligence and Deep Learning](./AI✅/) | Compared machine learning classifiers in a COVID-19 prediction case study using Python notebooks. |
| [C Programming](./C✅/) | Built a classroom booking system with user login, time-slot selection, and classroom matching. |
| [Data Visualization](./DV✅/) | Used Power BI to analyze a Portuguese hotel business and present strategic recommendations. |
| [Database Management](./Database✅/) | Designed a database for a food ordering platform. |
| [Fintech](./Fintech✅/) | Developed a Flask-based ETF trading prototype with market and sentiment features, a reinforcement learning decision layer, and portfolio backtesting. |
| [Operations Research](./Operation_Research✅/) | Applied operations research methods to a case study based on the 2024 Interdisciplinary Contest in Modeling (ICM). |
| [Optimization](./Optimization✅/) | Compared deep learning optimization algorithms for image classification using PyTorch. |
| [Statistics with R](./R✅/) | Analyzed factors associated with e-commerce sales using R and R Markdown. |
| [Supply Chain Management and Logistics](./SCML✅/) | Studied supply chain optimization for meal delivery. |
| [Simulation and Risk Analysis](./SRA✅/) | Used Monte Carlo simulation and queueing analysis to evaluate whether a milk tea shop should add staff during peak hours. |
| [Statistical Reasoning for Business Decisions](./SRBD✅/) | Evaluated the impact of promotional emails on customer conversion using A/B testing and the Hillstrom dataset. |
